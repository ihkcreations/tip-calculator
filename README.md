# Tip Calculator

This is a tip calculator web application that computes tip amounts and splits bills among multiple people.

## Features

- Preset tip percentage buttons
- Custom tip percentage input
- Bill splitting controls
- Real-time calculations

## How it works

The application listens for input events on the bill amount, custom tip, and split counter. Whenever a value changes, it computes the tip amount, total bill, and per person totals using JavaScript and updates the DOM immediately.

## Run

Open `index.html` in a browser. No install or build step.

## Files

- `index.html`: Main HTML markup structure
- `script.js`: Calculation logic and event listeners
- `style.css`: Stylesheet for layout and design
